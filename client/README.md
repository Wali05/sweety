# @sweety/client

The Sweety web client, built with React and Vite.

People can sign up, log in and log out, and the session is kept across reloads. The dashboard is only available when logged in: visiting it while logged out leads to the login page and back again afterwards, and logged-in users are sent from the login and signup pages to the dashboard. The dashboard is a placeholder for now; recording readings and viewing reports come next. From the repository root, run `npm run dev:client`.
